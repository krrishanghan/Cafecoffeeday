# ☕ Cafe Coffee Day – Power BI Analytics Dashboard

## 📌 Project Overview

This project presents an interactive **Cafe Coffee Day Analytics Dashboard** developed using **Microsoft Power BI**.

The dashboard focuses on analyzing beverage/product performance through metrics such as **quantity, calories and product-wise sales performance**.

The objective of this project is to transform raw cafe data into meaningful visual insights that can help understand product demand and performance.

---

## 🎯 Project Objectives

The main objectives of this project are:

- Analyze beverage/product performance
- Compare product-wise quantity
- Analyze calorie contribution across products
- Identify high-performing beverages
- Compare different beverage categories
- Understand product demand
- Create interactive and easy-to-understand visualizations
